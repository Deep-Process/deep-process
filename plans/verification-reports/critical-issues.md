## How to Add Issues

When verification discovers critical issues:

1. Add to appropriate severity section (BLOCKER, CRITICAL, HIGH)
2. Use template format
3. Include exact quotes and evidence
4. Provide clear recommendation
5. Add to resolution timeline if assigned

---

## How to Resolve Issues

When fixing critical issues:

1. Create a branch: `fix/critical-XXX`
2. Make changes according to recommendation
3. Update issue status: ⏳ Open → 🚧 In Progress → ✅ Resolved
4. Link to PR in issue
5. Re-verify after fix
